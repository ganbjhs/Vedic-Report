How the login works

  1. Set the account secrets once in .env on the server (a dedicated capture account, never a personal one): 
    X_USERNAME    the @handle (without the @)
X_PASSWORD    its password
X_EMAIL       X asks for it on unfamiliar logins
X_TOTP_SECRET only if 2FA is on
  2. That's it. The server signs in at startup and whenever a report finds the session missing or rejected.
  3. Optional fallback: generate the cookie by hand with python save_login.py x and place it at {{ sessions_dir }}/x_state.json.

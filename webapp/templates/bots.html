Using a key

  
curl -X POST {{ base_url }}/v1/run \
  -H "Authorization: Bearer vr_…" \
  -H "X-Actor: tg:12345678" \
  -H "Content-Type: application/json" \
  -d '{"links": ["https://x.com/…/status/…"], "name": "July fake accounts"}'

# → {"run_id": "…", "status": "queued", "link_count": 12}

curl {{ base_url }}/v1/run/<run_id> -H "Authorization: Bearer vr_…" -H "X-Actor: tg:12345678"
curl -OJ {{ base_url }}/v1/run/<run_id>/download/pdf -H "Authorization: Bearer vr_…" -H "X-Actor: tg:12345678"

  
No style, platform or options in the request — those live in the project, which is what keeps an integration one call wide. GET /v1/whoami answers "why was that refused" before it happens.
